# LASTLY Sprint 1 Spec

## Goal

완료한 생활 행동을 자연어(또는 음성)로 넣으면 행동과 날짜를 해석하고, 사용자가 확인한 뒤 마지막 수행 기록으로 남긴다. 조회(“언제 했어?”)와 주기 알림, 리스트/달력 보기를 지원한다.

## In

- 자연어 텍스트, 누르고 말하기, 수동(행동 이름·날짜)
- 접두어 `라스틀리`는 있으면 제거, 없어도 됨
- 발화유형 판별 후 **완료만** 확인·저장. **조회(`query`)** 는 저장하지 않고 목록에서 답함
- 확인: 화면 버튼 + (음성 입력 시) TTS 되묻기 + 말로 응/아니 → 결과 TTS(「기록했습니다.」/「취소했어요.」)
- 선택적 **알림 주기**(`schedule`): 확인·수정 칩, 또는 “N일마다 알려줘” 한 문장. 기본 없음
- 주기가 있으면 되묻기에 포함: “…기록하고, N일마다 알려줄까요?”
- 목록: 행동 / 마지막 수행일 / 경과일 / 주기·초과 표시. **리스트 | 달력** 토글
- 달력: 마지막 수행일 기준 점. 날짜 탭 시 그날 기록 시트
- 같은 정규화 행동명은 한 줄, 수행일만 갱신(주기 유지 가능)
- 목록 CRUD: 카드에서 이름·날짜·주기 수정, 오늘로 기록, 삭제
- 앱 진입 시 주기 초과 요약. 주기를 **처음 켤 때** OS 알림 권한 요청(거절해도 앱 안 표시 유지)

## Out

- 카테고리·가족 공유
- 전체 수행 히스토리 달력(이벤트 로그)
- 항상 듣기 호출어, 아이폰 지원 보장
- 계정·서버 DB·클라우드 STT/LLM 본선
- Qwen / Gemma / whisper-tiny 본선, e5 분류기

## 발화유형

| 유형 | 예 | 동작 |
|---|---|---|
| completed | 오늘 이불 빨았어 | 확인 후 저장 |
| query | 나 이불 빨래 언제 했어? | 목록 조회·답변 |
| planned | 내일 이불 빨 거야 | 저장 안 함 |
| incomplete | 오늘 이불 못 빨았어 | 저장 안 함 |
| uncertain | 지난주쯤 빨았던 것 같은데 | 저장 안 함 |

`못`/`안` 부정은 코드가 completed를 하드 차단한다. 모델 confidence는 되묻기 임계값에 쓰지 않는다.

## 브라우저 (STT 전략)

- **개발·실시간 받아쓰기 검증은 Safari 기준** (`http://localhost:5173`)
- **기본:** Web Speech 실시간 받아쓰기부터 시도 (Chrome·Safari 동일)
- **폴백:** 받아쓰기 오류·미지원일 때만 녹음 → `whisper-base`. Safari는 병행 녹음이 가능하면 빈 결과 시 Whisper로 이어서 처리
- Chromium에서는 받아쓰기와 `getUserMedia` 녹음을 동시에 쓰지 않음 (network 오류 유발)
- PWA로 설치해도 엔진은 설치한 브라우저를 따른다

## 모델

- STT 본선: Web Speech `ko-KR` 실시간
- STT 폴백: 녹음 → `onnx-community/whisper-base` WebGPU
- parse: 규칙 게이트 → 상대 날짜·주기 정규식 → `onnx-community/LFM2.5-350M-ONNX` q4 (completed/애매일 때만)
- Whisper와 LFM을 동시에 올리지 않음
- `@huggingface/transformers` v3.x (설치 기준)

## 전환 기준

- 골든셋에서 `못`/`안` 보존율이 낮으면 Whisper base 설정을 숫자로 고른다. tiny로 되돌리지 않음
- 예정/미완료 → 완료가 5% 초과면 규칙을 보강
- Android에서 LFM `.onnx_data` 로드 실패면 규칙+날짜만으로 동작

## 음성

- 탭 시작 / 탭 종료 / 무음 **1.5초** 자동 종료
- 완료 음성 기록 TTS: “{행동}을/를 {오늘|어제|M월 D일}로 기록할까요?” (주기 있으면 “…기록하고, N일마다 알려줄까요?”)
- 확인 답: 긍정만 저장 후 「기록했습니다.」, 부정은 「취소했어요.」. “어제”·“시트 세탁”처럼 말하면 행동/날짜를 고친 뒤 다시 묻는다. 화면 입력으로도 수정 가능
- 조회 답: “{행동}은/는 {날짜}에 했어요. {N}일 지났어요.”
- 애매하면 버튼으로만 확정

## 데이터

- IndexedDB (v3), 이 기기만. 로그인 없음
- 필드: 정규화 행동명, 마지막 수행일, 마지막 원문, 입력 경로, **schedule**, 수정 시각
- 알림 기한: `lastPerformedOn` + `schedule`. 다시 기록하면 수행일만 갱신되어 기한이 밀림
- 날짜는 KST
- 보기 모드(`list`|`calendar`)는 localStorage
