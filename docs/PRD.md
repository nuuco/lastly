# LASTLY PRD

| 항목 | 내용 |
|---|---|
| 제품 | LASTLY |
| 문서 상태 | Sprint 2 구현 반영 · 이후 요구사항의 단일 원천 |
| 기준 일자 | 2026-09-10 |
| 현재 단계 | Sprint 2 (지남/곧/여유 · 메모 · 검색 · 설정 · 알림함 · 음성·글 기록) |

이 문서는 **무엇을 만들지**의 기준이다. 기능을 더하거나 바꿀 때는 코드를 고치기 전에 이 문서를 먼저 고친다.

구현 세부는 `docs/MVP-SPEC.md`, 인식 평가 문장은 `docs/eval-utterances.md`를 본다.

---

## 1. 이 문서를 쓰는 방법

1. 새 요구·수정은 **미결 / 후보**에 한 줄로 적거나, 해당 FR을 고친다.
2. 합의되면 상태만 바꾼다. `후보` → `합의` → `구현됨`.
3. 범위를 빼면 **비범위**로 옮기고 이유를 남긴다.
4. 변경이 있으면 **변경 이력**에 날짜·요약을 한 줄 추가한다.
5. 문장 인식 기대값은 이 문서가 아니라 골든셋·픽스처가 원천이다.

상태 표기: `구현됨` · `합의` · `후보` · `보류` · `비범위`

---

## 2. 한 줄 정의

한 일을 **말로(또는 글로) 남기면**, 마지막 수행일과 주기를 기억하고, **언제 했는지** 물어보면 바로 답하는 개인용 생활 기록 앱.

핵심 문장: *말만 하면 챙겨드릴게요.*

---

## 3. 문제와 가치

반복되는 생활 일(빨래, 필터 교체, 청소)은 캘린더·할 일 앱에 넣기엔 가볍고, 메모에 넣으면 다시 찾기 어렵다. 사용자는 “했어”와 “언제 했지?”만 말하고 싶다.

LASTLY는 다음을 약속한다.

- **완료만 기록한다.** 예정·못 함·애매한 말은 저장하지 않는다.
- **한 줄만 남긴다.** 같은 일은 수행일만 갱신한다. 전체 히스토리 로그가 아니다.
- **확인 후에만 저장한다.** (알림함·목록의 「오늘 했어요」처럼 의도가 분명한 재기록은 예외로 바로 저장할 수 있다.)
- **이 기기에만 둔다.** 계정·서버·클라우드 인식 없이 동작한다.

---

## 4. 사용자와 맥락

| 구분 | 내용 |
|---|---|
| 1차 사용자 | 한국어로 생활 일을 혼자 챙기는 사람 |
| 사용 순간 | 방금 끝낸 직후, 또는 “이거 언제 했지?”가 떠오른 순간 |
| 입력 | 누르고 말하기가 본선. 글 입력·목록에서 직접 수정도 가능 |
| 기기 | 모바일 브라우저 PWA. 개발·실시간 받아쓰기는 Safari 기준 |
| 비사용자 | 가족 공유가 필요한 사람, 계정 동기화가 필요한 사람, 영어 전용 |

## 5. 제품 원칙

1. **확인 없는 저장은 없다.** 음성·글은 되묻거나 시트로 확정한다. 알림함·목록의 「오늘 했어요」는 예외.
2. **완료가 아니면 저장하지 않는다.** `못`/`안`은 완료로 올리지 않는다.
3. **홈이 본선이다.** 목록 + 마이크 + 시트/풀페이지. 설정·알림함은 보조 화면.
4. **온디바이스가 본선이다.** STT·파싱은 브라우저 안에서. 클라우드 API·웹푸시 서버를 본선으로 두지 않는다.
5. **같은 일은 하나로.** 이름이 같으면 갱신, 비슷하면 이을지 묻고 별칭을 남긴다. 동사만 같고 대상이 다르면 다른 항목이다.
6. **실패는 숨기지 않는다.** 못 알아들으면 풀페이지에 말하고, 다시 말하거나 직접 고치게 한다.
7. **알림은 거절해도 앱 안 표시는 남긴다.** OS 권한과 알림함·지남 요약은 분리한다.
8. **음성 안내는 끌 수 있다.** TTS는 설정으로 on/off. 끈 동안에는 말하지 않는다.

## 6. 목표와 비목표

### Sprint 1 (구현됨)

- 완료 발화 → 확인 → 마지막 수행 기록
- 조회, 리스트/달력, 주기, 목록 CRUD

### Sprint 2 (구현됨)

- 홈 **지남 / 곧 / 여유** 필터 + D-day
- 기록 **메모** (목록 부제)
- **검색** (제목·별칭·메모)
- **설정** (음성 안내 · 알림 on/off · 권한 · 받을 시간 · 주말 · 데이터 삭제)
- **알림함** + 오늘/다른 날/나중에 (앱을 열었을 때만, 서버 푸시 없음)
- 음성·글: 듣기 → **바로 이해** → 완료면 되묻기 / 거절이면 직접 고쳐 기록(풀페이지)

### 비목표

계정, 서버 DB, 웹푸시 서버, 클라우드 STT/LLM 본선, 가족 공유, 그룹 계층, 전체 수행 히스토리, 항상 듣기 호출어, 아이폰 네이티브, 영어 UX.

## 7. 핵심 흐름

```
[목록 | 달력]  ← 전체/지남/곧/여유 · 검색 · 종/톱니
    │
    ├─ 마이크 ── 듣기 ── 이해 ──┬─ 완료 → 이렇게 들었어요(풀페이지) → 저장
    │                           ├─ 조회 → 매칭 → 답변
    │                           └─ 거절 → 풀페이지에서 고쳐 기록 / 다시 말하기
    ├─ 키보드 ── 글 입력 ── 확인할게요 ── 같은 이해 파이프
    ├─ 카드 탭 ── 오늘/다른 날 갱신 · 내용 수정(풀페이지) · 삭제
    ├─ 종 ── 알림함 ── 오늘/다른 날/나중에
    └─ 톱니 ── 설정 (음성 안내 · 알림 · 데이터 삭제)
```

하단: 리스트|달력 토글(마이크 왼쪽) · 마이크 · 글 입력 전환(마이크 오른쪽).

## 10. 데이터

- IndexedDB (`lastly` **v5**). 이 기기만. 로그인 없음.

| 필드 | 의미 |
|---|---|
| actionKey / actionLabel | 정규화 키 · 표시 이름(제목) |
| lastPerformedOn | 마지막 수행일 |
| lastUtterance | 마지막 원문 |
| inputPath | voice \| text \| manual |
| schedule | 알림 주기 |
| aliases | 별칭 |
| memo | 자유 글 부제 (빈 문자열 허용) |
| snoozeUntil | 쉬어가기 날짜 (없으면 null). 그날까지 지남 요약·알림함에서 뺌 |
| updatedAt | 수정 시각 |

알림함 스토어 `inbox`: 앱 오픈 시 지남·곧에서 생성. 같은 항목+같은 기한은 중복 없음.

localStorage:

- 알림: `lastly.notifyEnabled`, `lastly.notifyTime`, `lastly.notifyWeekends`, `lastly.notifyAsked`
- 음성 안내: `lastly.voiceGuide` (`1`/`0`, 기본 켜짐)
- 보기 모드: `lastly.viewMode` (`list` \| `calendar`)

빈 DB면 샘플 기록을 한 번 넣을 수 있다(설정 메뉴로는 다시 넣지 않음).

## 11. 플랫폼·인식

(Sprint 1 STT/LFM과 동일. 개발·실시간 STT는 Safari 기준, Chromium은 Whisper 폴백.)

**PWA 알림 한계:** 홈 화면 설치만으로는 지정 시각 예약 알람이 오지 않는다. 서버 웹푸시 없이는 앱을 연 순간에만 알림함·OS Notification이 동작한다.

## 12. UX 카피

| 위치 | 문구 |
|---|---|
| 헤드라인 | 말만 하면 챙겨드릴게요 |
| 서브 | 한 일을 말하면 기억해요. 언제 했는지도 물어볼 수 있어요. |
| 빈 목록 | 아직 기록한 일이 없어요. … |
| 상태 필터 | 전체 / 지남 / 곧 / 여유 |
| 검색 | 제목·메모 검색 |
| 듣기 | 듣고 있어요 |
| 이해 중 | 문장을 이해하고 있어요 |
| 거절 제목 | 직접 고쳐 기록 |
| 글 입력 CTA | 확인할게요 |
| 수정 저장 | 저장할게요 |
| 거절 후 저장 | 이대로 기록할게요 |
| 저장 TTS | 기록했습니다. |
| 취소 TTS | 취소했어요. |
| 알림 한계 안내 | 앱을 열었을 때만 알려 줘요. 꺼진 앱을 깨우지는 않아요. |
