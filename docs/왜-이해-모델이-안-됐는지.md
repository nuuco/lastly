# 왜 예전 이해 AI는 안 됐고, 지금은 되나

한 줄: **요리를 바꾼 게 아니라, 꺼지던 가스레인지를 바꿨더니 불이 붙었습니다.**

---

## 예전에 안 된 이유

LASTLY는 말을 글로 받은 다음, **할일·날짜·주기**를 뽑아 확인 화면에 보여 줍니다.

예전에는 이 이해를 **LFM**이라는 작은 모델이 맡았습니다. 모델 파일은 있었는데, 브라우저가 그걸 여는 프로그램(**ONNX Runtime**)이 켜지자마자 죽었습니다.

그래서

- 문장을 이해하다가 틀린 게 아님
- **시작도 못 함**
- 앱은 조용히 **규칙(오늘/어제, 했어 같은 패턴)** 만으로 넘어감
- “되는 것 같은데 AI는 안 돈 것”처럼 보임

확인 페이지에 나오던 `9966304`, `10290256` 같은 숫자가 그 꺼짐 신호입니다.

Safari에서 특히 자주 꺼졌고, Chrome에서도 세션이 안 열리는 경우가 있었습니다.

---

## 지금은 되는 이유

다른 프로젝트에서 이미 된 방식을 가져왔습니다.

| | 예전 | 지금 |
|---|---|---|
| 이해 모델 | LFM 350M | **Gemma 3 1B** (4비트, 약 670MB) |
| 여는 프로그램 | ONNX Runtime | **MediaPipe** (브라우저 WebGPU용) |
| 확인 | 세션이 안 열림 | Chrome에서 JSON이 나옴 |

**모델만 바꾼 게 아닙니다.** 브라우저에서 꺼지던 여는 프로그램도 바꿨습니다. Gemma는 그 프로그램에 맞춰 만든 웹 파일입니다.

Chrome에서 짧은 한국어 → JSON은 됩니다.

- 어제 빨래했어 → 완료 · 빨래 · 어제
- 시트 세탁 언제 했지 → 조회 · 시트 세탁

Safari·GPU 없는 기기는 아직 규칙만 씁니다. 받아쓰기(Web Speech)는 그대로입니다.

---

## 허깅페이스 토큰 — 이렇게 하면 됩니다

Gemma는 게이트 모델입니다. **받을 때** 토큰이 필요합니다. 사용자 앱에 토큰을 넣지 않습니다.

개발자(또는 모델 파일을 서버에 올려 두는 사람)만:

1. https://huggingface.co/google/gemma-3-1b-it 에서 라이선스 동의 (Kaggle Authorize가 뜨면 Authorize)
2. https://huggingface.co/settings/tokens 에서 **Read** 토큰 발급
3. 프로젝트 루트 `.env`에 `HF_TOKEN=hf_...` (`.env.example`을 복사)
4. `npm run download:gemma`
5. 파일은 `public/models/`에 생김. **git에 넣지 않음** (약 670MB)

그다음 Chrome에서

- 앱 홈 → **모델 받기** (한 번 동의)
- 또는 http://localhost:5173/gemma-check.html

사용자에게는 토큰이 안 보입니다. 나중에 제품에서는 우리가 올려 둔 파일을 Wi-Fi 동의 후 받게 하면 됩니다.

## 앱에서 돌았는지 보는 법

확인 화면 아래 작은 글:

- **문장을 이해해 봤어요** → Gemma가 돈 것
- **문장 규칙으로 이해했어요** → 모델 없이 규칙만
- **자세한 이해는 직접 확인해 주세요** → 모델은 켜졌는데 열리다 실패

「어제 빨래했어」는 규칙도 맞춰서, 이 문구로 구분하는 게 확실합니다.
