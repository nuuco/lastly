# 온디바이스 이해 모델 전환

## 결론

- 이해 실패 원인은 모델 품질이 아니라, 브라우저에서 LFM을 열던 런타임(ONNX Runtime)이 세션을 생성하지 못한 점.
- 런타임을 MediaPipe(WebGPU)로, 모델을 Gemma 3 1B(4비트)로 교체한 뒤 Chrome에서 슬롯 추출이 동작함.
- Gemma는 게이트 모델이므로 Hugging Face Read 토큰으로 파일을 받은 뒤 사용함. 토큰은 앱에 넣지 않음.

## 이전 (LFM)

- 역할: 받아쓴 문장에서 의도·할일·날짜·주기 추출
- 상태: 모델 파일은 있으나 브라우저 세션이 열리지 않음
- 결과: 규칙(오늘/어제, 했어 등)만으로 동작. AI 미사용과 구분이 어려움

## 현재 (Gemma)

- 런타임: MediaPipe LLM Inference, Chrome WebGPU, Web Worker
- 모델: `gemma3-1b-it-int4-web.task` (약 670MB)
- 확인된 예
  - 어제 빨래했어 → 완료 · 빨래 · 어제
  - 시트 세탁 언제 했지 → 조회 · 시트 세탁
- Safari 및 WebGPU 미지원 환경은 규칙만 사용
- STT(Web Speech)는 변경 없음

## 개발 환경 준비

1. https://huggingface.co/google/gemma-3-1b-it 라이선스 동의
2. https://huggingface.co/settings/tokens 에서 Read 토큰 발급
3. `.env.example`을 `.env`로 복사 후 `HF_TOKEN=hf_...` 기입
4. `npm run download:gemma`
5. 산출물: `public/models/` (git 제외)

이후 Chrome에서 앱 홈의 「모델 받기」 또는 `/gemma-check.html`로 확인.

## 동작 여부

확인 화면 하단 문구

- 문장을 이해해 봤어요: Gemma 사용
- 문장 규칙으로 이해했어요: 규칙만 사용
- 자세한 이해는 직접 확인해 주세요: 모델 로드 실패
